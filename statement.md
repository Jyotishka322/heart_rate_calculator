# Project Statement

## Problem Statement

Manually calculating heart rate in Beats Per Minute can require a user to perform a small mathematical calculation. This project provides a simple Python program that accepts the number of heartbeats counted and the time taken, then calculates BPM automatically.

## Scope

The project focuses on a command-line educational application. It calculates BPM from user-provided heartbeat count and time. It also validates input, classifies the result into simple ranges and stores calculation history.

The project does not measure heart rate automatically and does not provide medical diagnosis.

## Target Users

- Students learning Python
- Beginners learning problem solving
- Users who want a quick BPM calculation

## High-Level Features

1. User input
2. Input validation
3. BPM calculation
4. BPM classification
5. Result display
6. JSON history storage
7. Automated testing
